# 06 · 现代大模型的架构变体

## 先识别变体改变了哪条计算路径

基础 Block 的信息流见[第 04 章](04-transformer.md)。变体可以组合，但作用于不同对象：位置机制影响匹配关系，头共享改变 KV 表示，FFN 门控改变特征变换，专家路由改变计算分配，窗口/状态压缩改变历史访问。执行内核另属一个维度。

| 设计 | 主要改动 | 资源收益与代价 |
| --- | --- | --- |
| Pre-Norm / RMSNorm | 子层尺度与归一化方式 | 影响优化与执行，需配合整体参数化 |
| RoPE | Q/K 的位置相关变换 | 不增加完整位置表，但长度外推需适配 |
| SwiGLU | FFN 的内容与门控分支 | 增加一组投影，成本要结合中间宽度 |
| MQA / GQA | Query 到 K/V 头的共享映射 | 减小每位置缓存与相关投影，限制独立 K/V 表示 |
| MoE | Token 选择部分专家执行 | 扩大总容量，但增加路由、负载和通信 |
| 窗口/稀疏注意力 | 可直接访问的位置集合 | 减少连接与部分状态，改变信息路径 |
| SSM / 混合架构 | 历史传播和状态更新 | 固定/较小状态与精确回读之间有取舍 |

## RoPE 怎样把位置放进匹配

RoPE 对 Q/K 成对的特征维度施加随位置变化的旋转，点积因此带有相对位置关系；V 通常不旋转。它不同于在 Embedding 上相加一个位置向量，也不同于因果 Mask：旋转改变分数，Mask 规定连接是否允许。

缓存的旧 K 与新 Q 必须采用一致的位置与旋转规则。常见实现保存旋转后的 K，继续生成时用新的绝对位置生成 Q/K，不能重复旋转历史。修改位置缩放或重用不同位置下的缓存会改变计算语义。

改变最大长度只改变接收上限，不保证模型学会使用更长上下文。旋转频率/缩放、长序列训练、不同位置的检索能力和资源预算需一起验证。依据：[RoFormer](https://arxiv.org/abs/2104.09864)。

## SwiGLU 的两条扩展路径如何汇合

```math
\mathrm{SwiGLU}(x)=\left(\mathrm{SiLU}(xW_g)\odot xW_u\right)W_d
```

一条投影生成内容，另一条经 SiLU 生成门控，同维元素相乘，再经下降投影回隐藏宽度。门控不是调用外部规则，它随输入变化并由训练学习；多个位置独立应用同一组参数。

三组矩阵与两矩阵 FFN 不可在同样中间宽度下直接宣称成本一致。中间激活、融合布局与 TP 两支的切片对齐都会影响执行；矩阵划分见[Serving](10-serving-and-distributed.md)。

## MHA、MQA、GQA 到底共享哪一部分

| 形式 | Query 头数 | K/V 头数 | 每个 Query 使用什么 |
| --- | --- | --- | --- |
| MHA | `h_q` | `h_q` | 自己对应的一组 K/V |
| MQA | `h_q` | 1 | 所有查询共享唯一 K/V |
| GQA | `h_q` | `h_kv` | 按组映射到某个 K/V 头 |

每个 Q 头仍形成不同的分数与内容组合；共享的是被匹配和读取的 K/V，不是把所有 Q 平均成一个。缓存随 `h_kv` 增长，高效内核可读取同一物理 K/V 服务一组 Q，没必要把缓存扩展复制到 `h_q`。

收益包括更小 K/V 投影、状态和相关读流量，但 Query 与历史匹配工作仍存在，总延迟不必按头数同比下降。改变共享程度要对应训练或适配，不能直接删除既有 MHA 权重中的头并假定质量不变。依据：[MQA](https://arxiv.org/abs/1911.02150)、[GQA](https://arxiv.org/abs/2305.13245)；逐层读写见[第 09 章](09-inference-and-memory.md)。

## MoE：从路由到合并是一次真正的数据搬运

常见稀疏 MoE 用多个 FFN 专家替换稠密 FFN，路由器按当前 Token 表示选择少数专家：

```math
y=\sum_{i\in\mathrm{TopK}(g(x))}\alpha_i\,E_i(x)
```

路由先得到专家索引与混合权重；dispatch 按专家聚集输入并保存原位置映射；专家分别执行矩阵计算；combine 把结果送回原位置并按权重相加。一个 Token 选择多个专家时，其表示和结果可能产生多份路由数据；共享专家又增加始终执行的路径。

专家分布在不同设备时，dispatch/combine 产生通信。热门专家会让某些 rank 等待，过小专家批次又难以发挥矩阵效率。容量、负载均衡目标和是否丢弃/改派/等待 Token 都要按具体实现说明。训练还需相应梯度回传，并使路由学习不被少数专家垄断。

总参数包含所有专家，决定存储；单 Token 激活参数较少，只描述部分算术。一个批次不同 Token 可覆盖许多专家，不能据激活参数推断整个批次只访问少量权重。卸载未激活专家也会引入后续搬运。专家分工由训练形成，不是人工指定的学科模块。依据：[Switch Transformers](https://arxiv.org/abs/2101.03961)。

## 稀疏访问与压缩状态改变不同的信息边界

窗口注意力不直接读取窗口外历史，多层可通过中间位置传播；稀疏连接保留特定远程通道。SSM 将历史更新进状态，后续输入读取压缩状态，而不是任意回读所有历史 K/V。混合模型可组合不同模块。

较小状态有利于容量，却必须保留未来可能需要的信息。全注意力保留历史表示以便新查询重新选择，资源随长度增长。比较时要看精确检索、长程关系、训练并行与硬件执行，不能只看复杂度标签。研究入口：[Mamba](https://arxiv.org/abs/2312.00752)。

不同缓存表示不能一律套标准 K/V 头公式。公开配置与官方实现是判断实际架构的依据，不推测未公开模型内部设计。

## 混合架构：同一模型可以维护不同的历史状态

长上下文需要在保留可回读信息与限制状态大小之间取舍。递归模块将旧状态与当前输入合成新状态；Gated Delta Network（门控 Delta 网络）属于这类路径，通过门控与增量更新维护关联状态。它不是简单丢掉一批旧 K/V，也不等同于所有 SSM。模型可以把这类模块与 Attention 层交替使用，再在特征变换部分组合 MoE。

[Qwen 官方仓库](https://github.com/QwenLM/Qwen3.8)说明 Qwen3.5 采用 Gated Delta Networks 与稀疏 MoE，Qwen3.8 延续其架构基础。这里引用其公开设计，不将所有尺寸的具体层比例或状态格式视为相同；信息核实于 2026-10-21。

混合执行时，一部分层读取按位置组织的 K/V，另一部分层消费更新后的递归状态。后者在固定模型配置下可不随历史逐位置增长，但不能据此宣称整个模型状态固定大小：Attention、局部卷积等模块仍有各自的历史。继续生成需要一套相互对齐的状态，而非仅一张标准 KV 块表。[第 09 章](09-inference-and-memory.md)解释容量口径，[第 18 章](18-inference-engineering.md)解释分叉与回退。

## 跨层复用与阶段分工改变了哪些计算

[DeepSeek-V4.1-Flash 报告](https://arxiv.org/abs/2609.19969)公开 Causal Encoder-Decoder（CED，因果编码器—解码器）与 Compressed Sparse Attention 2（CSA2，第二代压缩稀疏注意力）：前者改变上半部全局 KV 的生成来源，后者允许指定层复用前层的全局 KV，部分模式也复用稀疏选择索引。报告还结合 FP4（4 位浮点）全局 KV 缓存；表示精度与跨层共享是不同优化。各层自己的 Query 与局部滑窗状态仍需区分；它不是把全部层合成一层，也不是把所有状态都共享。

这里的 encoder 是该模型内部的因果计算阶段，不能直接套用原始翻译 Transformer 的双向 encoder 假设。理解阶段优化时，应先找清“哪些状态已由前段提供、后段还缺什么”，再判断能省掉哪些前向工作。跨层复用改变架构与训练约定，不能作为任意现成模型的无损开关；缓存的具体保存与恢复见[推理引擎](18-inference-engineering.md)。

## FlashAttention 属于执行优化而非新的头结构

FlashAttention 用分块和在线归一化减少 HBM 中间读写，通常保持标准注意力语义，而不是改成稀疏连接。全注意力算术量仍随序列长度平方增长，浮点结果可能有差异。

它可以与 GQA、RoPE 和门控 FFN 同时使用。不同优化减少的资源不一样，整体瓶颈可能转移到 KV、FFN、通信或调度。内核机制见[第 16 章](16-transformer-implementation.md)，容量与请求执行见[第 18 章](18-inference-engineering.md)。
